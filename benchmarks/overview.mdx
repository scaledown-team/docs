ScaleDown models are small and built for one job each: **Classify**, **Extract**, **Summarize** and **Compress**. We benchmark each against leading general-purpose models on public datasets, and compare accuracy, cost and latency side by side.

## What we measure

| Task | Benchmark | Metric |
|---|---|---|
| Classify | CLINC OOS | Accuracy |
| Extract | CUAD | F1 |
| Summarize | QMSum | ROUGE-L |
| Compress | FinanceBench | F1 |

Each comparison reports:

- **Accuracy**: ScaleDown versus each model in a provider's lineup, on the benchmarks above.
- **Cost**: price per 1K requests for every model compared.
- **Latency**: response time per task.

## Example: ScaleDown vs OpenAI

Against the OpenAI lineup (GPT-5.5, GPT-5.4 Mini, GPT-5.4 Nano), ScaleDown averages **8.72% higher accuracy** than the OpenAI average:

| Task | Accuracy vs OpenAI avg |
|---|---|
| Classify | +5.40% |
| Extract | +14.40% |
| Summarize | +8.83% |
| Compress | +6.23% |
